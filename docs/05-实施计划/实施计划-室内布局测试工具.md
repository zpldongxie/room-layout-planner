# 实施计划：室内布局测试工具

> 版本：v1.0 | 日期：2026-08-10 | 依赖：PRD + TECH 确认后

## 开发顺序（Phase 划分）

### Phase 1：画布基础（半天）
- [ ] 单 HTML 骨架 + 三栏布局（家具面板/画布/属性面板）
- [ ] Canvas 初始化 + 网格绘制 + 缩放/平移（滚轮、空格拖动）
- [ ] 坐标转换（mm ↔ px）

### Phase 2：户型绘制（1 天）
- [ ] 画墙模式：点击起点→终点生成墙体，墙厚可设
- [ ] 闭合检测（终点接近起点自动闭合房间）
- [ ] 墙体渲染（双线/粗线 + 长度标注）
- [ ] 模板户型（预置 2 个：一居室/两居室）

### Phase 3：家具库 + 拖入（1 天）
- [ ] 家具类型元数据（8 种 + 默认尺寸表）
- [ ] 家具面板 UI（图标 + 名称 + 默认尺寸）
- [ ] 拖入画布 + 拖动移动 + 选中高亮
- [ ] 旋转（←→ 键 5°/步 + 旋转手柄拖拽 + 输入框）
- [ ] 复制/删除/清空

### Phase 4：吸附 + 碰撞（1-1.5 天）
- [ ] 吸附开关 + 阈值设置
- [ ] 网格吸附 / 墙体吸附 / 家具间吸附
- [ ] 碰撞检测：家具↔家具（SAT）+ 家具↔房间（越界）
- [ ] 碰撞处理：block 模式（阻止+回弹）/ warn 模式（红色高亮）
- [ ] 状态栏碰撞提示

### Phase 5：持久化 + 导出（0.5 天）
- [ ] localStorage 自动保存/恢复
- [ ] 导出 PNG（Canvas toBlob）
- [ ] 导出/导入 JSON

### Phase 6：验收打磨（0.5 天）
- [ ] 边界测试（最小尺寸、极端角度、多家具密集摆放）
- [ ] 性能检查（100 家具拖拽流畅）
- [ ] UI 细节打磨（选中态、吸附视觉反馈、碰撞动画）

**总计约 5-6 个工作日**（单开发工具全时）。

## 验收标准（摘自 PRD §8）

1. ✅ 能画出至少一个闭合房间
2. ✅ 8 种内置家具均可放入并显示
3. ✅ 家具可移动、可旋转任意角度
4. ✅ 默认尺寸生效，可单独改尺寸
5. ✅ 吸附开关生效
6. ✅ 碰撞提示生效（变红/阻止）
7. ✅ 导出 PNG / JSON 可用

## 里程碑

- M1（Phase 1-2 完成）：能画户型 → CEO 验证画墙体验
- M2（Phase 3 完成）：家具可拖入旋转 → CEO 验证交互
- M3（Phase 4 完成）：吸附碰撞可用 → CEO 验证核心算法
- M4（Phase 5-6 完成）：可持久化导出 → 全量验收
