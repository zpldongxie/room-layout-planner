# PRD：室内布局测试工具（Room Layout Planner）

> 版本：v1.0 | 日期：2026-08-10 | 状态：待 CEO 确认

## 1. 产品定位

一个**纯前端单页面应用**，用于快速测试室内家具摆放布局。用户自己画户型图 → 选择家具拖入房间 → 自由旋转/移动 → 自动吸附与碰撞检测，快速验证"这个房间能不能放得下/怎么摆更合理"。

**使用场景**：装修前规划、家具购买前尺寸验证、多方案试摆对比。
**形态**：单页面 Web 应用，无需后端，浏览器直接打开。

## 2. 目标用户

- 主要用户：CEO（用于自己家/朋友家装修规划测试）
- 无需登录，打开即用

## 3. 核心功能清单

### P0（MVP 必须）
| # | 功能 | 说明 |
|---|------|------|
| 1 | 画户型图 | 用户自由绘制房间墙体（直线墙），可设置墙厚，形成闭合房间 |
| 2 | 家具库 | 内置常见家具：沙发、茶几、电视柜、餐桌、餐椅、床、电脑桌、学习桌（可扩展） |
| 3 | 家具尺寸设置 | 每个家具可自定义长×宽；不设置时使用默认尺寸（基于常见家具标准） |
| 4 | 拖入房间 | 从家具面板点击/拖拽放入房间画布，可自由移动位置 |
| 5 | 任意旋转 | 选中家具后旋转任意角度（0-360°），支持角度输入框精确控制 |
| 6 | 自动吸附 | 开关控制：家具边缘靠近墙/其他家具边缘/网格线时自动吸附对齐 |
| 7 | 碰撞检测 | 家具之间、家具与墙体之间自动检测重叠/越界，视觉提示（变红/阻止/警告） |

### P1（体验增强）
| # | 功能 | 说明 |
|---|------|------|
| 8 | 网格辅助线 | 画布背景网格（默认 100mm/格），帮助对齐 |
| 9 | 测量标注 | 显示墙体长度、家具尺寸标注 |
| 10 | 家具复制/删除 | 右键或按钮复制、删除已放置家具 |
| 11 | 导出布局图 | 导出为 PNG 图片 / JSON 数据（可再次载入） |
| 12 | 多房间 | 支持一个户型内画多个房间（客厅/卧室/厨房等） |
| 13 | 户型模板 | 预置 1-2 个常见户型模板（一居室/两居室） |

### P2（远期可加）
- 3D 预览、家具样式/颜色选择、门窗绘制、面积计算、分享布局链接

## 4. 用户故事

- 作为用户，我想画出我家户型的墙，这样能知道空间边界
- 作为用户，我想把沙发拖进客厅试试摆哪合适，这样能判断尺寸是否合适
- 作为用户，我想旋转餐桌看横放还是竖放更省空间
- 作为用户，我想让家具自动吸附到墙边，这样摆放整齐不用手动微调
- 作为用户，我想知道两个家具是否放得下（是否碰撞），这样避免买回来摆不下

## 6. 交互流程

```
打开页面
  ↓
① 画户型：选择"画墙模式" → 点击画布起点 → 拖动/点击终点 → 生成墙体
  ↓（也可选择模板户型直接开始）
② 选家具：左侧家具面板点击"沙发" → 拖入画布（或点击后出现在画布中心）
  ↓
③ 调整：选中家具 → 拖动移动 / 滚轮或手柄旋转 / 右侧面板改尺寸
  ↓
④ 自动吸附：开启吸附开关 → 家具靠近墙/家具/网格时自动对齐（吸附距离阈值可调）
  ↓
⑤ 碰撞检测：摆放时实时检测，重叠区域红色高亮 + 不可放置（或警告）
  ↓
⑥ 导出 PNG / JSON 保存方案
```

## 7. 非功能需求

- 纯前端单页（HTML + JS + Canvas），无需构建工具也可运行（或极简构建）
- 支持鼠标操作（PC）即可；触屏支持放 P1
- 画布可缩放（滚轮缩放）、平移（空格+拖动或中键）
- 操作流畅：家具数量 ≤ 100 时无卡顿
- 所有数据本地保存（localStorage 自动保存当前方案，防丢失）

## 8. 验收标准

1. ✅ 能画出至少一个闭合房间（墙体可闭合）
2. ✅ 8 种内置家具均可放入房间并显示
3. ✅ 家具可移动、可旋转任意角度
4. ✅ 不设置尺寸时使用默认尺寸，可单独改尺寸
5. ✅ 吸附开关生效（开=吸附，关=自由摆放）
6. ✅ 家具重叠/越墙时出现碰撞提示（红色高亮或阻止）
7. ✅ 导出 PNG 可正常打开、导出 JSON 可重新载入

## 9. 边界与约束

- 家具最小尺寸限制：≥ 100mm（防止缩到看不见）
- 家具不能完全重叠放置（碰撞模式开启时）
- 墙厚默认 120mm（可调 60-400mm）
- 画布逻辑尺寸：最大 20m × 20m（超出提示）
- 单位：毫米（mm），比例 1m = 50px（可缩放）
