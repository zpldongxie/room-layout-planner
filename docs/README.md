## 技术栈

| 项 | 选择 |
|----|------|
| 形态 | 单页 HTML + CSS + JS（Canvas 2D） |
| 依赖 | 无第三方库 |
| 持久化 | localStorage + JSON 导出 |
| 运行 | 浏览器双击 index.html 即用 |

## 开发顺序

1. Phase 1 画布基础 → 2. Phase 2 户型绘制 → 3. Phase 3 家具拖入 → 4. Phase 4 吸附碰撞 → 5. Phase 5 持久化导出 → 6. Phase 6 验收打磨
